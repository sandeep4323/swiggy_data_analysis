# 🍽️ Swiggy Restaurant Data Analysis using Python

A comprehensive **Exploratory Data Analysis (EDA)** project on a Swiggy restaurant dataset. This project analyzes restaurant pricing, customer ratings, food categories, delivery performance, and city-wise trends to generate meaningful business insights using Python.

---

# 📁 Dataset

The project uses the **swiggy.csv** dataset containing restaurant-related information such as:

### Restaurant Information
- Restaurant Name
- City
- Food Type
- Price
- Average Ratings
- Total Ratings
- Delivery Time

---

# 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / VS Code

---

# 🧹 Data Cleaning

The following preprocessing steps were performed:

- Checked missing values
- Removed duplicate records
- Simplified food categories
- Verified data types
- Prepared the dataset for analysis and visualization

---

# 📊 Exploratory Data Analysis

The following analyses were performed:

## Distribution Analysis
- Restaurant Price Distribution
- Food Type Distribution (Top Categories)

## Relationship Analysis
- Price vs Average Ratings
- Average Price by City and Food Type
- Correlation Between Numeric Variables

## Performance Analysis
- Top 10 Highest Rated Restaurants
- Top 10 Fastest Delivery Restaurants
- Top 10 Slowest Delivery Restaurants

## Summary Analysis
- Pivot Table Analysis
- Business Insights

---

# 🔑 Key Insights

- Food prices vary significantly across restaurants and cities.
- Most restaurants fall within a moderate price range.
- Restaurants with higher prices do not always receive higher customer ratings.
- Delivery time differs across restaurants, highlighting operational efficiency differences.
- Some restaurants consistently maintain high ratings despite receiving a large number of customer reviews.
- Heatmap analysis reveals relationships between price, ratings, total ratings, and delivery time.
- City-wise pivot table analysis helps identify pricing trends for different food categories.
